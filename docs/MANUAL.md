# Wintec TK2 Converter 機能概要と操作マニュアル

**バージョン 1.10.0**（2026-11-21）　※ 使っている版は、画面のタイトルの `v1.10.0.230` のような表示で確かめられます。版ごとの変更は「バージョン履歴.md」にあります

GPS ロガーの走行ログを、Google Earth で見られる形に変換し、サーキットやジムカーナのラップタイムを解析・比較する Windows 用のツールです。

---

## 1. できること

### 変換ツール
- Wintec WBT-201 の `.tk2` ログを、**NMEA（.nmea）** と **Google Earth 用の KMZ / KML** に変換します
- WBT-201 は GPS の週番号の仕様で日付が約 19.6 年（1024 週）前にずれて記録されるため、**正しい日付に直して**出力します
- 前後の不要な部分の**カット**、Google Earth で**走行をアニメーション（ツアー）**で再生する KMZ も作れます

### 解析ツール
| 機能 | 内容 |
|---|---|
| コース定義を作成 | 何周か走ったログから、コースの形・スタート / ゴールのライン・セクターのラインを作ります。ジムカーナ（1 本ずつ走るコース）にも対応 |
| ラップ解析 | ラップタイム・セクタータイム・最高速を計算します。ピットインでセッションを分け、ベストに印を付け、CSV に保存できます |
| 比較 | 選んだ周回を地図の上で並べて再生、距離ごとの速度の比較 |
| 走行動画 | 車載カメラの動画とログの時刻を合わせ、周回ごとの切り出し、2 本の動画を並べた比較再生、速度やタイムを重ねた表示。ペダルなど別のカメラの動画（サブ動画）を小さく重ねる、表示の位置を画面で直す |
| その他の表示 | 動画の音声からエンジン回転数・ギアを推定、腕時計（FIT ファイル）の心拍を表示 |
| データをまとめる / ライブラリから比較 | ログ・解析結果・動画・心拍を 1 つのフォルダにまとめ、別の日・別のログの周回どうしを比べます |

読み込めるログ: Wintec の `.tk2`、他社ロガーの `.nmea`（5Hz など）。

---

## 2. 準備

- **Windows 10 / 11** と **.NET 10 デスクトップ ランタイム**（入っていなければ、起動時に案内が出ます）
- 動画を使う機能だけ **ffmpeg** が必要です（コマンドプロンプトで `winget install Gyan.FFmpeg`）
- KMZ を見るには **Google Earth Pro**（デスクトップ版）

このフォルダの中身:

| ファイル | 内容 |
|---|---|
| `WintecTK2Converter.exe` | 本体。ダブルクリックで起動 |
| `tk2nmea.ini` | 変換の細かい設定（KMZ の色・ツアーのカメラなど）。テキストエディターで編集 |
| `overlay_default.ini` | 動画に重ねる表示の既定のレイアウト |
| `WintecTK2Converter.settings.json` | 画面の位置や入力値の記憶（自動で作られます） |

---

## 3. 起動

`WintecTK2Converter.exe` を起動すると、**「変換ツール」「解析ツール」**を選ぶ画面が出ます。

- **変換ツール** … `.tk2` の変換の画面が開きます
- **解析ツール** … 「コース定義を作成...」「ラップ解析...」「ライブラリから比較...」から選びます

開いた画面を閉じると、この選ぶ画面に戻ります（選ぶ画面を閉じると終了）。
`.tk2` ファイルやフォルダを exe に直接ドラッグ＆ドロップすると、変換の画面がすぐ開きます。

---

## 4. 変換ツールの使い方

1. `.tk2` ファイル（複数可）またはフォルダを、画面へ**ドラッグ＆ドロップ**します（「ファイルを追加...」でも可）
2. 一覧でファイルを選ぶと、記録の範囲と停止していた区間が左下に出ます
3. 前後を切りたいときは「開始カット」「終了カット」に時刻を入れます（例 `08:05:00`、空欄なら切らない）
4. 右側で出力先・出力形式（KMZ / KML / NMEA だけ）・高さの表示・ツアーの有無を選びます
5. **「変換する」**を押します。「出力フォルダを開く」で結果を確認できます

できる KMZ をダブルクリックすると Google Earth Pro で開き、速度で色分けされた走行の線が出ます。

---

## 5. 解析ツールの使い方

おおまかな流れ: **コース定義を作る → ラップ解析 →（動画の時刻合わせ）→ 比較**

### 5.1 コース定義を作る（コースごとに最初の 1 回）
1. 「コース定義を作成...」で、そのコースを何周か走ったログを追加します（周回が多いほど正確）
2. 種類（サーキット / ジムカーナ）を選んで**「解析する」**を押すと、コースの形とラインが自動で置かれます
3. 右の地図でラインの位置を確かめ、必要ならセクターの数や位置を直します
4. **「コース定義を保存...」**で `*.course.json` に保存します

### 5.2 ラップ解析
1. 「ラップ解析...」で、コース定義と走行ログを選び**「解析する」**を押します
2. セッション（ピットから出て戻るまで）ごとに、周回のタイム・セクター・最高速が並びます
   - ★ = 全体のベスト、※ = セッションのベスト。アウトラップ・IN ラップは区別して表示
   - ドライバー名を入れると、ログごとに自動で保存されます
   - セッションの分け方が違うときは、周回表を右クリックして分割・結合できます
   - 「基準差」の列に、基準の周回とのラップタイムの差（＋ = 遅い）が出ます。基準は初め全体のベストで、周回表を右クリックして「この周回を基準にする」で変えられます
3. 周回を選んで「比較再生」「距離ごとに比較」で、走り方の違いを見られます
4. 「CSV に保存...」で表計算ソフトに持っていけます

### 5.3 走行動画を使う（ffmpeg が必要）
1. ラップ解析でセッションを選び、**「走行動画の時刻合わせ・切り出し...」**を開きます
2. 「開く...」で動画を選び、ログとの時刻を合わせます。周回を 1 つ選び、動画をコマ送りしてコントロールラインを通った瞬間を出し、「このコマが選んだ周回の開始」を押します（一度合わせれば保存されます）
3. 合わせると、次のことができます
   - 周回ごとの**切り出し**（速度・タイムなどの表示を焼き込むこともできます）
   - 「音声を解析」でエンジン回転数・ギアを推定
   - 「FIT を開く...」で腕時計の心拍を表示
   - **「サブ動画を開く...」**でペダルなど別のカメラの動画を小さく重ねます。「音声で合わせる」で 2 本の時刻を自動で合わせ、トリミングで余分な所（焼き込みの日付など）を隠せます
   - **「表示の編集...」**で、速度計・タイム・サブ動画などの表示の ON / OFF と位置を、画面の上でドラッグして直せます（別のファイル `overlay_user.ini` に保存）
4. ラップ解析で周回を 2 つ選び **「▶ 動画で比較...」**を押すと、2 本の動画を並べて同時に再生します（サブ動画もそれぞれに重ねます）
   - 開くと、動画・ラップ解析・地図を自動で並べます（「並べて配置」）。手で位置や大きさを直したら、「並べて配置」ボタンを右クリックして**「現在のレイアウトを保存」**を選ぶと、次からその並べ方になります。「初期レイアウトを保存」で初めの並べ方に戻ります
   - 「揃える位置」でセクターの開始を選ぶと、そこを 0 秒にして再生し、地図のタイム差もそこで 0.00 秒、そこからの差になります
5. 「動画素材を書き出す...」で、Resolve などに重ねる透明の素材を書き出せます（「サブ動画も含める」でサブも入れられます）

### 5.4 データをまとめて、別の日の周回と比べる
1. ラップ解析の **「データをまとめる...」**で、ログ・解析結果・動画・心拍を 1 つのフォルダにまとめます
   （コースのフォルダ ＞ 日付とログ名のフォルダ。動画はコピーが既定。フォルダごと移動しても使えます）
2. 解析ツールの **「ライブラリから比較...」**でそのフォルダを開くと、まとめたすべての周回が並びます
3. ドライバー・日付・動画の有無で絞り込み、比べたい周回を **A・B** に入れて「▶ 動画で比較」または「地図で比較」を押します

---

## 6. 困ったとき

- **日付がおかしい**: 変換ツールの「補正する週数」を空欄（自動）にしてください。0 にすると補正しません
- **周回がうまく取れない**: コース定義のラインが、車が止まる位置より手前にあるか確かめてください。GPS が大きくずれているログ（カメラの GPS など）は周回が取れないことがあります
- **動画が開けない**: ffmpeg が入っているか確かめてください
- **細かい設定・すべての機能の説明**: リポジトリの `docs/USAGE.txt` を見てください
